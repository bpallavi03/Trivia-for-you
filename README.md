# 🌍 Trivia For You

Trivia For You is a globally accessible quiz platform built using React.js and AWS cloud services. The application features continent-based quizzes, map quizzes, worldwide trivia, score tracking, randomized question generation, and responsive interactive UI components.

## 🚀 Live Demo

Frontend hosted on AWS CloudFront + S3:

```bash
https://d3ecr7td8c89mm.cloudfront.net/
```

## 🛠️ Technologies Used

- React.js
- JavaScript
- AWS S3
- Amazon CloudFront
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- Amazon CloudWatch
- GitHub Actions
- Framer Motion
- HTML5 / CSS3

## ✨ Features

- 🌎 Worldwide trivia quizzes
- 🗺️ Interactive map quiz
- 🌍 Continent-based quizzes
- 🧪 Science and geography categories
- 🎯 Dynamic score tracking
- 🔀 Randomized question generation
- 📱 Responsive UI design
- ⚡ Fast global delivery with CloudFront CDN
- ☁️ Serverless AWS deployment

## ☁️ AWS Architecture

- Frontend hosted on Amazon S3
- Global CDN delivery using Amazon CloudFront
- Serverless APIs using AWS Lambda + API Gateway
- Scalable quiz data management with DynamoDB
- Automated deployments using GitHub Actions

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/bpallavi03/trivia-for-you.git
```

Move into project folder:

```bash
cd trivia-for-you
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build production files:

```bash
npm run build
```

## 🚀 Deployment

The project is deployed using:

- Amazon S3
- Amazon CloudFront
- GitHub Actions CI/CD

Every push to the main branch automatically deploys the latest build to AWS infrastructure.
